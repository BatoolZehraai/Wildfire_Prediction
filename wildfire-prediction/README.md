# Probabilistic Wildfire Spread Prediction

A Machine Learning and Probabilistic Modeling application designed to simulate and predict the spread of wildfires (focused on Canada data). This project leverages data science workflows to evaluate environmental risks, generate spread maps, and optimize prediction accuracy using ensemble sampling methods.

## 🚀 Features
* **Probabilistic Modeling:** Simulates fire spread trends using advanced probabilistic and ensemble sampling.
* **Risk Mapping:** Generates spatial risk maps to visualize potential wildfire paths and intensities.
* **Loss Evaluation:** Tracks training performance and loss metrics to ensure high model fidelity.
* **Modular Codebase:** Clean separation of data processing, modeling logic, and experiment notebooks.

## 🛠 Tech Stack
* **Language:** Python
* **Data & Math:** `numpy`, `pandas`, `scipy`
* **Visualization:** `matplotlib`, `seaborn`
* **Frameworks:** Python's standard data science ecosystem
